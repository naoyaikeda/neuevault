## 概要と目的

Vault 内に散乱している添付ファイル（画像、PDF、音声、動画等）を検出し、運用ルール（`AGENTS.md`）および Obsidian 設定（`.obsidian/app.json` の `attachmentFolderPath`、デフォルト: `Archives/`）に従って指定の格納先へ安全に集約・整理します。

移動の際、衝突（バッティング）しやすいファイル名（数字のみ、`Image`, `Image 1` 等）を検出した場合は、参照元ノートのタイトルをプレフィックスとして付与して衝突を防止し、Markdown 内のリンク参照（Wikilink や標準 Markdown リンク等）を自動で追従更新します。

## ルール規約

1. **格納先ディレクトリ**:
   - `AGENTS.md` および `.obsidian/app.json` に基づき、添付ファイルの標準格納先は `Archives/`（または設定されたアタッチメントフォルダ）とします。
2. **衝突（バッティング）防止ルール**:
   - 以下のいずれかに該当するファイル、または同名ファイルが既に格納先に存在するファイルはリネームを行います：
     - **数字のみ** (例: `01.png`, `1017.jpg`, `20260817030204.jpg`)
     - **`Image` や `Image <数字>`** (例: `Image.jpg`, `Image 1.png`, `Image (1).jpg`)
     - **非常に短い汎用名** (4文字以下の英数字で、単一ノートのみから参照されているもの)
   - **リネーム命名規則**:
     - 参照元ノートが存在する場合: `[ノート名プレフィックス]_[元ファイル名]`  
       *(例: `プロジェクト計画書` から参照されている `Image 1.png` ➔ `プロジェクト計画書_Image 1.png`)*
     - 参照元ノートが存在しない場合: `unused_[元ファイル名]`
   - ノート名にファイル名禁止文字（`/ \ : * ? " < > |` 等）が含まれる場合はアンダースコア等に自動置換してサニタイズします。

## ワークフロー

### 1. 対象ファイルの検出

格納先ディレクトリ（`Archives/`）、`.obsidian/`、`.git/`、`.agents/`、`_templates/` 以外の場所に配置されている添付ファイル（`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.bmp`, `.pdf`, `.mp3`, `.mp4` 等）を特定します。

### 2. 移動および衝突防止リネーム処理の実行

1. 格納先ディレクトリ（`Archives/`）が存在することを確認（無ければ作成）。
2. 同一内容の重複ファイルが既に格納先にある場合は余剰ファイルを整理。
3. 各ファイルについて参照元 Markdown ノート（`[[filename]]`, `![](filename)` 等）を特定。
4. 上記「衝突防止ルール」に従い、必要に応じて `[ノート名プレフィックス]_[元ファイル名]` へリネームしつつ移動。

### 3. Markdown内リンク参照の更新

- ファイル名のリネームや移動に伴い、影響を受ける全 Markdown ファイル内のリンク記述（`[[元ファイル名]]` -> `[[新ファイル名]]`, `(元ファイル名)` -> `(新ファイル名)` 等）をすべて自動更新します。

### 4. 完了検証

- 格納先以外の場所に添付ファイルが残っていないこと（検出件数 0 件）を確認して完了とします。

## 使用方法・実行手順

### AI エージェントによる整理
エージェントがアセットを整理する際は、本スキルのルール規約に従って格納先フォルダへの移動と Markdown リンクの書き換えを行います。

### スクリプトによる検出・一括処理

付属の Python スクリプトを実行することで、散乱した添付ファイルの検出、衝突防止リネーム、リンク更新を一括自動実行できます：

**散乱している添付ファイルの確認（チェックのみ）**:
```bash
python .agents/skills/arrange-assets/scripts/arrange_assets.py --check
```

**移動・リンク更新の事前プレビュー（Dry Run）**:
```bash
python .agents/skills/arrange-assets/scripts/arrange_assets.py --dry-run
```

**添付ファイルの集約を実際に実行**:
```bash
python .agents/skills/arrange-assets/scripts/arrange_assets.py --apply
```

※ デフォルトでは `.obsidian/app.json` の設定値（または `Archives`）を格納先としますが、`--target-dir <フォルダ名>` オプションで任意のディレクトリを指定することも可能です。
